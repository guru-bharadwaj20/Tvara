# Decision 0001: C++20 core

Status: accepted for the initial implementation.

The workload needs read-only mapped tensors, explicit cache ownership, and CPU
intrinsics. C++20 provides spans and standard threads while integrating with the
installed GCC compiler and established CMake builds. Start with standard-library
code rather than introducing a large runtime dependency.

Tradeoffs: memory safety requires bounds validation, sanitizer runs, and invariant
tests. C++ compiler ABIs vary, especially between MinGW and MSVC. Expose a narrow
C ABI to Python so compiler-specific C++ objects never cross that boundary.
Use scalar kernels as the required baseline; optimized paths must be optional.
